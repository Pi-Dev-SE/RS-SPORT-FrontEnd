## 📖 Description

**RS SPORT** is a web application built with Angular that helps sports clubs efficiently manage their teams, players, and administrative tasks. The platform offers tools for tracking player performance, handling medical reports, managing training sessions, and more.


## 🚀 Features

- 🧑‍🤝‍🧑 Manage players, coaches, and team staff
- 📅 Schedule and manage training sessions
- 🩺 Track player health and injury reports
- 📈 Monitor player performance with charts
- 🔐 Role-based authentication (Admin, Coach, Medical Staff)
- 🧾 Real-time collaboration 
- 📱 Responsive and mobile-friendly design

## 🛠️ Tech Stack

- **Frontend:** Angular, TypeScript, HTML, SCSS
- **Backend :** Spring Boot / Node.js / FastAPI
- **Database :**  MySQL
- **Other Tools:** Chart.js, ngx-charts, Bootstrap or Tailwind CSS, Angular Material, Cloudinary
